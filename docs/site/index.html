What a shaliach is not

  • Not a chatbot with opinions. It doesn't tell you what you could do. It opens a browser and does it.
  • Not someone else's cloud. It runs on a machine you own, under your own Claude account.
  • Not unsupervised. Anything risky waits for your tap, from the Mac app or the iPhone app.
  • Not a black box. The source is on GitHub. Read every line before you hand it the keys.

Questions people ask

What is Shaliach?

Shaliach is a team of always-on Claude Code agents that runs on your own Mac or server. You text one agent, Atlas, the chief of staff; Atlas hires the agents the job needs, gives each one its own browser and terminal, and asks you on your phone before anything risky happens. There is a Mac app, an iPhone app and a web board.

Can I run Claude Code agents from my phone?

Yes. You chat with Atlas and the team from the iPhone app (or the web board in any browser), approve risky steps with one tap, and watch any agent's screen live. The iPhone app builds from source with a free Apple ID; there is no Android app yet.

Where do my messages, code and files go?

To your machine and nowhere else we run. Shaliach has no cloud of its own. Threads, files and agent workspaces live on the server or Mac you install it on. The agents talk to Anthropic the same way Claude Code always does, under your account. Voice calls are optional and go to OpenAI only if you add your own API key.

Does it touch my Claude login? Is this within Anthropic's terms?

Every agent is the unmodified claude CLI. You sign in with Claude's own claude auth login; the CLI keeps and refreshes its login, and Shaliach never stores your Claude token. Nothing is resold or pooled. Some questions about always-on use on consumer plans have no written answer yet, and we list them openly in docs/terms-questions.md. If you run it for a business, an API key under Anthropic's commercial terms is the safer choice.

What will it cost me in tokens?

Shaliach is free for non-commercial use. The agents use your Claude plan, exactly like Claude Code sessions you start yourself. Five agents working at once use it about five times as fast as one. Start with one or two agents and watch your usage on the first day. We have not published a "typical cost" because we have not measured one we trust.

Which platforms work?

Server: Ubuntu 24.04 or Debian 12 (x86_64 or arm64), or macOS. Mac app: macOS 14+, Apple silicon. iPhone app: builds from source with a free Apple ID (one command; re-run it every 7 days to re-sign). Any browser: the web board, through an SSH tunnel. There is no Android app yet and no Windows support.

What can the agents do on my machine?

Anything their Unix user can do. They run Claude Code in bypassPermissions mode so they do not stall on prompts. The approval cards (Allow once / Always / Deny) stop risky steps, but they are a convenience, not a sandbox. On a server with agent desktops on, the service user is in the docker group, which is root-equivalent. So use a VPS that does nothing else. The Mac bridge, which lets agents run jobs on your Mac, is off until you turn it on, logs every job, and can be stopped from the menu bar.

What is exposed to the internet, and how is it authenticated?

The deck binds 127.0.0.1 only. On a public server, Caddy passes only /v1 and /healthz over HTTPS on 443, and ufw allows only SSH and 443. Every /v1 call needs a bearer token, compared in constant time; with no token set, the API refuses everything. Each paired phone or Mac gets its own token, stored only as a hash and revocable. Wrong guesses are rate limited. Want nothing public at all? Install with --ssh-tunnel or use Tailscale. Secrets are plain files with 0600 permissions, not encrypted at rest. Full detail: docs/security.md.

Is it open source?

No. It is source-available under the PolyForm Noncommercial License 1.0.0. You can read every line, run it and change it for any noncommercial use. Running it for a company needs a business licence; ask on GitHub.

Did an AI write this?

A lot of the code, yes: most of it was written by Claude Code agents, many of them running inside Shaliach, with a human designing, reviewing and testing every change. If something here reads wrong, open an issue and it gets fixed.

How is this different from OpenAI dots, Meta Muse or Grok Bot?

Those rent you an agent in their cloud, with no setup. Shaliach is a team of agents on hardware you own, on the Claude plan you already pay for, and you can read the code that runs them. The trade-off is real: you run one install command and look after a server.
