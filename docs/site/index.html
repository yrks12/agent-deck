Shaliach

Your AI emissaries. A whole team that works for you.

A chief-of-staff agent hires, briefs and runs a team of Claude Code agents on your own Mac or server. You text one agent and it runs the rest. Watch them work and approve what matters from your phone.

View on GitHub Latest release →

What you get

A whole team

Atlas hires the agents it needs, briefs each one and hands out the work.

Own computers

Every agent gets its own browser and terminal. Watch any screen live, or take over.

You approve

Risky steps stop and wait for your tap, from the Mac app or the iPhone app.

Yours to run

Your laptop or your server, your Claude plan. Source-available, free for noncommercial use.

Install

1. Server or Mac

curl -fsSL https://raw.githubusercontent.com/yrks12/shaliach/main/install.sh | bash

2. Mac app (macOS 14+, Apple silicon)

curl -fsSL https://raw.githubusercontent.com/yrks12/shaliach/main/scripts/install-mac.sh | bash

Each script prints what it will do, and running it again upgrades. Every agent is a real Claude Code session and uses your own Claude account.
