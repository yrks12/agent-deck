Shaliach vs Grok Bot

xAI opened Grok Bot in beta in August 2026: always-on bots that sign in to your tools and work while your laptop is off. Shaliach is the self-hosted version of that idea, built on Claude Code.

Atlas, the short answer: Grok Bot runs its bots on a cloud computer xAI provides, inside a SuperGrok Heavy or Cursor plan. Shaliach runs the team on hardware you own, each agent with its own browser and terminal, on your own Claude plan, with code you can read.

Which one fits

Pick Grok Bot if

  • you already pay for SuperGrok Heavy or Cursor's top plans
  • you want bots working while every machine of yours is off
  • you want no server to look after

Pick Shaliach if

  • you want the agents, their browsers and your logins on hardware you own
  • you already pay for a Claude plan and want to use it around the clock
  • you want several agents working as a team, and to watch or take over any of them
  • you want to read the code before you hand it the keys

Questions

Is Shaliach a Grok Bot alternative?

Yes: both give you always-on agents that work while you are away. Grok Bot runs them in xAI's cloud; Shaliach runs a team of Claude Code agents on your own Mac or server.

Do Grok Bot's bots share one computer?

Coverage differs: Unite.AI says the bots share a single cloud computer, iPhone in Canada describes "its own cloud-based virtual computer". In Shaliach each agent has its own browser and terminal.

Which model does Shaliach use?

Claude, through Claude Code, under your own Claude account.
