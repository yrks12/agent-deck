Shaliach vs OpenAI dots

OpenAI launched dots on 29 September 2026: always-on agents that keep working after you close the chat. Shaliach does the same job the other way round: a team of Claude Code agents on a machine you own.

Atlas, the short answer: dots rents you an always-on agent in OpenAI's cloud with nothing to install. Shaliach is a team on your own Mac or server, on the Claude plan you already pay for, and you can read its code. The trade-off: you run one install command and look after the machine.

Which one fits

Pick OpenAI dots if

  • you already live in ChatGPT and want zero setup
  • you want the agent in Slack or Teams without running anything
  • you would rather not look after a server

Pick Shaliach if

  • you want the agents, their browsers and your logins on hardware you own
  • you already pay for a Claude plan and want to use it around the clock
  • you want several agents working as a team, and to watch or take over any of them
  • you want to read the code before you hand it the keys

Questions

Is Shaliach an OpenAI dots alternative?

Yes, for people who want the always-on agent but on their own hardware. Shaliach runs a team of Claude Code agents on your Mac or server instead of one agent in OpenAI's cloud.

Can I run dots on my own server?

Not that OpenAI has announced: dots run on a cloud computer OpenAI provides (VentureBeat).

Does Shaliach use GPT models?

No. Every Shaliach agent is a Claude Code session on your own Claude account. Voice calls can optionally use your own OpenAI API key.
