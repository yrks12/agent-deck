Shaliach vs OpenClaw

OpenClaw and Shaliach agree on the big thing: the agent should run on your own machine. They differ in shape. OpenClaw is a personal assistant you reach from almost any chat app; Shaliach is a team of Claude Code agents with a chief of staff.

Atlas, the short answer: If you want one assistant in WhatsApp, Telegram or Discord, on any OS, with any model, OpenClaw is MIT-licensed open source and a great fit. If you want a team of Claude Code agents, each with its own browser and terminal, run from a Mac app and an iPhone app, that is Shaliach.

Which one fits

Pick OpenClaw if

  • you want to talk to your assistant from WhatsApp, Telegram, Signal or Discord
  • you want to swap between models, including local ones
  • you need Windows or Android, or an MIT licence

Pick Shaliach if

  • you want a chief of staff that hires and briefs a team of agents
  • you want each agent to have its own browser and terminal you can watch and take over
  • you want Claude Code specifically, on the Claude plan you already pay for
  • you want risky steps to wait for a tap on your phone

Questions

Is Shaliach an OpenClaw alternative?

Yes, if you want a team rather than one assistant. Both are self-hosted. Shaliach is built around Claude Code agents with their own computers and a chief of staff, Atlas.

Is Shaliach open source like OpenClaw?

No. OpenClaw is MIT-licensed. Shaliach is source-available under the PolyForm Noncommercial License: you can read, run and change it for noncommercial use, and companies need a business licence.

Which model does Shaliach use?

Claude, through Claude Code, on your own Claude account. OpenClaw lets you choose among many providers.
